# گزارش آزمون و وضعیت تحویل

تاریخ گزارش: ۲۴ نوامبر ۲۰۲۶

Next.js `16.4.6` با Node.js `26.13.0` محیط ساخت آزمایش شد. `.nvmrc` برای ساخت Cloudflare Pages روی Node.js `22.23.4` تنظیم شده و `package.json` حداقل نسخهٔ لازم Next.js (`20.9.0`) را اعلام می‌کند.

## وضعیت پیاده‌سازی

انتشار نخست شامل هدر، معرفی اصلی، هر ده دسته، درباره و فوتر است. چون هنوز دادهٔ تأییدشدهٔ شعبه، حساب فروشنده، شبکهٔ اجتماعی یا تماس مرکزی در دسترس نبود، این بخش‌ها در خروجی عمومی و ناوبری ظاهر نمی‌شوند. مدل داده، اعتبارسنجی و گردش‌های آن‌ها پیاده شده و در پیش‌نمایش توسعه با رکوردهای نمایشی آزمایش شده است.

## بررسی‌های ایستای انتشار نهایی

| بررسی | نتیجه |
|---|---|
| `npm run typecheck` | موفق |
| `npm run lint` | موفق |
| `npm run validate:content` | موفق؛ ارجاع‌های شعبه و دسته، وضعیت انتشار و URLها بررسی شدند |
| `npm run build` | موفق؛ پیش از ساخت، اعتبارسنجی خودکار محتوا و fixtureها اجرا شد؛ خروجی ایستا در `out/` ساخته شد |
| HTML تولیدی | ده کارت دسته، عنوان فارسی نهایی، canonical، metadata، robots، sitemap و صفحهٔ ۴۰۴ تولید شدند؛ دادهٔ نمونه در خروجی نبود |
| خروجی Pages | `out/_headers` فقط برای میزبان‌های `pages.dev` مقدار `X-Robots-Tag: noindex` می‌گذارد؛ دامنهٔ اصلی از این قاعده مستثنا است |
| مرز سمت‌کاربر | محتوای صفحه در Server Component باقی می‌ماند؛ منو/تم و کشف شعبه به Client Componentهای مجزا محدود شده‌اند |
| محدودهٔ مقصد بیرونی | اعتبارسنجی `scopeId` برای دسته و شعبه انجام می‌شود؛ مقصد منتشرشدهٔ شعبه به شعبهٔ منتشرشده وابسته است |
| گالری دسته‌ها | در کد، breakpointها با طرح هم‌راستا هستند: ۴ ستون از ۱۰۲۴، ۲ ستون از ۴۸۰ تا ۱۰۲۳ و ۱ ستون زیر ۴۸۰ پیکسل |
| اندازهٔ کنترل‌ها | دکمه‌های آیکنی، اقدام‌های دسته، لینک‌های اطلاعات شعبه و انتخاب‌گرها حداقل ۴۴ پیکسل ارتفاع دارند |
| لینک‌های خروجی | در همان زبانه باز می‌شوند و مقصدهای شعبه/دسته در همان کارت مرتبط قرار می‌گیرند |
| مسیر ناموجود | فایل ۴۰۴ فارسی در خروجی استاتیک ساخته می‌شود؛ وضعیت HTTP باید در میزبان نهایی هم تأیید شود |

## بررسی تصویری و تعاملی این نوبت

مرورگر بازبینی با انتخاب مالک، Chromium/Playwright بود. اجرای Playwright CLI به دلیل نبود دسترسی شبکه به `registry.npmjs.org` و اجرای مستقیم Playwright به دلیل نصب‌نبودن Chromium در محیط شکست خورد؛ بنابراین اسکرین‌شات تازه، مرور بصری، تعامل با منو/تم/فیلتر و آزمون روی مرورگرهای دیگر در این نوبت انجام نشده است. موارد قبلی که در نسخهٔ پیشین این گزارش ثبت شده بودند، برای CSS و اجزای تازه‌شدهٔ این نوبت مدرک محسوب نمی‌شوند.

## موارد باقی‌مانده برای انتشار واقعی

- حساب Cloudflare و DNS در این محیط به سایت وصل نشده‌اند؛ استقرار، TLS، تغییر DNS، ریدایرکت `www` و `pages.dev`، دسترسی از شبکه‌های ایران و شبکهٔ خارج ایران هنوز باید انجام و ثبت شوند.
- Cloudflare Pages پیش‌نمایش‌ها را به‌طور پیش‌فرض با `X-Robots-Tag: noindex` می‌فرستد؛ فایل `_headers` این رفتار را برای هر دو الگوی `pages.dev` صریح می‌کند. URLهای پیش‌نمایش به‌طور پیش‌فرض عمومی هستند، پس مالک باید سیاست Access را در داشبورد Pages برای پیش‌نمایش‌ها فعال کند. [راهنمای انتشارهای پیش‌نمایش Cloudflare Pages](https://developers.cloudflare.com/pages/configuration/preview-deployments/) · [راهنمای فایل `_headers`](https://developers.cloudflare.com/pages/configuration/headers/)
- بررسی دستی با صفحه‌خوان و آزمون کامل WCAG 2.2 AA انجام نشده است. بازبینی کنتراست و دستگاه‌های واقعی iOS و Android و مرورگرهای Firefox و Safari نیز باقی است.
- سه اجرای Lighthouse موبایل و traceهای LCP/CLS اجرا نشده‌اند، چون ابزار Chrome DevTools MCP در این نشست در دسترس نیست. برای تکمیل این معیار، سرور `chrome-devtools` را به MCP متصل کنید تا اندازه‌گیری انجام شود.
- اطلاعات واقعی شعب، شماره‌ها، ساعات، عکس‌ها، مقصدهای دقیق دیجی‌کالا و اسنپ و حساب‌های رسمی اجتماعی هنوز باید از مالک دریافت و تأیید شوند. fixtureهای `src/data/preview-fixtures.ts` فقط برای توسعه هستند و وارد build تولیدی نمی‌شوند.
